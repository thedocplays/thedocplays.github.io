Heritage Protocol

A card is legal if it was printed in a Standard-legal set (formerly Type 2) set within the Magic Multiverse.

  • Allowed: All Standard sets (Alpha to present) AND any card released prior to June 17, 2011 (Vintage legal).
  • Banned: Commander Precons, Modern Horizons, Supplemental Sets, and Universes Beyond (released after 2011).
  • Ban List: Uses the official Commander Ban List.
